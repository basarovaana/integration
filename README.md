# Калькулятор интегралов

## Описание проекта

Программа предназначена для вычисления определённых и неопределённых интегралов рациональных функций.

Поддерживаются:

- аналитическое вычисление неопределённого интеграла;
- численное вычисление определённого интеграла методом трапеций;
- построение графика первообразной;
- проверка корректности введённой функции;
- обработка ошибок пользовательского ввода.

Проект реализован на языке Python с использованием объектно-ориентированного подхода.

# Возможности программы

## Неопределённый интеграл

Программа умеет:

- интегрировать степенные функции;
- интегрировать функции вида `1/x`;
- применять линейность интеграла;
- интегрировать некоторые рациональные дроби.

### Пример

```text
f(x) = x^2 + 1/x

F(x) = 1/3x^3 + ln|x| + C
```

## Определённый интеграл

Для вычисления определённого интеграла используется метод трапеций.

Пользователь вводит:

- нижний предел интегрирования;
- верхний предел интегрирования;
- количество разбиений.

### Пример

```text
∫(x^2)dx от 0 до 3 = 9.000
```

## Построение графика

После вычисления интеграла программа может построить график первообразной функции.

Для построения используется библиотека `matplotlib`.

# Описание модулей

## main.py

Главный файл программы.

Отвечает за:

- меню;
- взаимодействие с пользователем;
- выбор режима работы;
- обработку ввода.

## integration.py

Абстрактный базовый класс для калькуляторов интегралов.


## indefinite_integral.py

Модуль аналитического вычисления неопределённого интеграла.

Реализует:

- правило степени;
- интегрирование `1/x`;
- обработку рациональных выражений;
- линейность интеграла.


## definite_integral.py

Модуль вычисления определённого интеграла методом трапеций.


## function_parser.py

Преобразует пользовательский ввод в вычислимое выражение Python.

## validator.py

Проверяет корректность введённой функции.

## formatter.py

Отвечает за форматирование результата.

## visualizer.py

Строит график первообразной функции.


## tests.py

Содержит модульные тесты проекта.
